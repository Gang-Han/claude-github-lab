Claude + GitHub Lab

This project demonstrates a simple workflow between Claude Code, local Git, GitHub, and GitHub Pages.

What this demo shows

  • Editing and generating code locally with Claude Code
  • Tracking changes with Git and pushing them to GitHub
  • Publishing the result automatically with GitHub Pages

This website was edited locally with Claude Code and published through GitHub, showing how AI-assisted development can fit into a normal Git and GitHub workflow.
